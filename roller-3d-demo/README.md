# GRILA 3D Roller Blind — standalone preview

Open index.html through an HTTPS web server such as GitHub Pages. Uses Three.js from a public CDN, so internet access is required.

## Controls
Play separates parts; Pause stops motion; Assemble reverses to exact original group positions; Reset camera restores the initial view; slider scrubs the animation. Drag and pinch to orbit and zoom.

## Geometry disclaimer
Concept only. Tube diameter 30 mm is confirmed. Width, drop, bottom rail, end caps and mounting hardware are provisional. Warm taupe woven fabric and dark brown rail approximate product references. Not validated manufacturing CAD.

## Publishing
If GitHub Pages serves the repository root, visit /roller-3d-demo/ on its Pages domain. Do not replace the repository's root index.html or modify the production website.

## Testing
Confirm rendering, all five controls, camera orbit/zoom, and reassembly on Android, tablet and desktop browsers. Browser interaction is not yet verified.
